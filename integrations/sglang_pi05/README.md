# EmbodiRun SGLang Pi05 integration

This optional package owns the LeRobot Pi05 checkpoint compatibility pipeline.
Install it only in the managed SGLang inference environment. The managed entry
point is `embodirun-sglang-pi05-serve`; the historical `rlinf-sglang-pi05-serve`
name remains a compatibility alias, and EmbodiRun's own `embodirun-sglang-serve`
launcher stays a thin wrapper in the root package.
