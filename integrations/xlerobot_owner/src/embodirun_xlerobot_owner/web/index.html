操作前确认

短流程，任何异常优先 Stop。

operator
  1. 验证 连接会话，确认控制权不在其他操作者手中。
  2. 观察 三路画面和服务连接都已回读，再进入沉浸式 VR。
  3. 接管 双手追踪且没有握住 grip 时点击 Arm，移动时持续握住对应 grip，扳机控制对应夹爪。
  4. 释放 松开某侧 grip 只释放该侧 clutch；页面隐藏、追踪丢失或网络拥塞才会触发全局 Stop。
