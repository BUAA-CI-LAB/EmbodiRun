# 实验与测量

这里汇总推理传输、相机采集和机器人接入实验，介绍运行配置、测量方法和结果。

安装与运行请先阅读 [快速开始](quickstart.md)。
[支持矩阵](support-matrix.md) 列出了可用的集成。
每个实验都说明了其输入，以及使用回放、仿真
还是实体设备。

## 实验目录

| 实验 | 研究问题 | 主要结果 |
|---|---|---|
| [推理传输](inference-transport.md) | 传输方式如何影响推理延迟？ | 在测试局域网上，小型 JPEG 负载下 WirelessComm 的吞吐约高 4.5%；延迟主要由模型执行与排队决定。 |
| [仅相机采集](camera-only-experiments.md) | 采集负载与连接故障如何影响观测下发？ | 只读相机发布器支持成对回放测量、实时采集以及 TCP 断连测试。 |
| [传输候选方案](transport-experiments.md) | 共享内存、原始帧、GStreamer、Zenoh 或 NIXL/UCX 能否降低延迟？ | 已作为可选路径实现并在本地测试。在测试硬件上，尚无一种展示出加速或更好的恢复能力。 |
| [LightNav-0 与 XLeRobot](lightnav0_xlerobot.md) | 解码后的本地路点能否驱动 XLeRobot 底盘？ | 绑定及其 CPU 测试已存在。真实检查点评估、导航成功率以及实机校验仍未完成。 |
