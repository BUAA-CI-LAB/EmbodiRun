# Code of Conduct

EmbodiRun follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The text adopted by this project is
[`CODE_OF_CONDUCT.md`](https://github.com/BUAA-CI-LAB/EmbodiRun/blob/main/CODE_OF_CONDUCT.md)
in the repository root. The reporting and enforcement process is summarized below.

## Scope

The Code of Conduct applies in all project spaces — issues, pull requests,
discussions, code review, and documentation — and when an individual is
officially representing the project in public, for example through an official
account or at an online or offline event.

## Reporting

Report abusive, harassing, or otherwise unacceptable behavior to the project
maintainers at **cclonelycc@outlook.com**. Reports are reviewed promptly and
fairly, and the privacy and security of the reporter are respected.

For a security vulnerability, use the
[security policy](https://github.com/BUAA-CI-LAB/EmbodiRun/blob/main/SECURITY.md)
for private reporting instructions.

## Enforcement guidelines

Maintainers apply the Contributor Covenant Community Impact Guidelines:

| Level | Community impact | Consequence |
|---|---|---|
| 1. Correction | Inappropriate language or unprofessional behavior | Private written warning; a public apology may be requested |
| 2. Warning | A single incident or a series of actions | Warning with consequences for continued behavior; no interaction with those involved for a set period |
| 3. Temporary ban | A serious violation, including sustained inappropriate behavior | Temporary ban from public or private interaction with the community |
| 4. Permanent ban | A pattern of violations, harassment of an individual, or aggression toward a class of individuals | Permanent ban from public interaction within the community |

Maintainers may remove, edit, or reject comments, commits, code, wiki edits,
issues, and other contributions that are not aligned with the Code of Conduct,
and will communicate the reasons for moderation decisions when appropriate.
